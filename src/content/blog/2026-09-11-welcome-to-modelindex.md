MODELINDEX started as a single tool: tell us your GPU, RAM, and context needs, and we'll
rank the Ollama-compatible models that actually fit. This blog is where we'll write up
the things that don't fit in a finder result — methodology notes, model family deep
dives, and changes to how we measure VRAM and speed.

Posts here are plain markdown files committed to the repo, the same way code changes
are: written, reviewed, and merged through a pull request. No separate CMS to log into.
