MODELINDEX

Ollama model index by GPU

Rank library tags for a GPU and context length. Layout follows the OpenRouter picker and Artificial Analysis leaderboard; metrics are local: VRAM, speed (decode tok/s), latency (TTFT), quant, and fit (full / partial / OOM).

Speed
Decode tokens/s after the prompt is ingested. Artificial Analysis output speed.
Latency
TTFT @ 128 tok = 128/prefill + 1/decode. Ollama prompt_eval_duration plus one decode step.
VRAM
Weights + KV cache at the selected context. Fit is full, partial offload, or OOM.
Quant
GGUF file type. Q4_K_M is Ollama’s usual default; Q8_0 and F16 are higher precision.
